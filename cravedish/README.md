# CraveDish — Stitch Four-Page Working Website

This build follows the uploaded Stitch design reference:
- Home page
- Restaurants page
- Restaurant / Order Details page
- Profile & Orders page

Design system is based on the Stitch "Crimson Feast" palette and Plus Jakarta Sans typography.

Functional demo:
- 51 Chennai-area restaurants
- 15 dishes per restaurant (765 catalog items)
- Search/filter restaurants
- Open a restaurant and add dishes
- Quantity controls and live totals
- Place orders
- Cancel placed orders
- Order history
- Add/change delivery addresses
- Persistent cart/orders/addresses via localStorage
- Responsive layout

Open `index.html`.
No server/build step is required. Internet access is needed for Google Fonts and food photography URLs.
