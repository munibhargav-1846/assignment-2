# 🌐 Multi-App Interactive Website

### 🚀 One Website. 12 Applications. One Connected Experience.

Welcome to our **Multi-App Interactive Website** project! 🎉

This project brings together 12 popular applications in one main website. The website features an interactive globe containing the logos of all the applications. Users can click on an application logo to open its corresponding application.

Our main objective is to create a simple, interactive, and visually appealing platform that connects multiple applications through a single interface.

---

## ✨ Key Features

* 🌍 **Interactive Globe:** Displays application logos in a circular globe layout.
* 🖱️ **Click-to-Open Navigation:** Click an app logo to open its corresponding application.
* 🎨 **Consistent Design:** Preserves the original website theme and visual appearance.
* 🔗 **12 Integrated Applications:** Provides access to all applications from one main website.
* 📱 **User-Friendly Interface:** Makes application navigation simple and convenient.
* 🛠️ **Collaborative Development:** Developed by a team of 7 members using GitHub branches.

## 📂 Project Overview

The project consists of a main website and the application files integrated into it.

* 🌐 **Main Website:** Displays the interactive globe and application logos.
* 🖼️ **Application Logos:** Represent the individual applications.
* 🔗 **Navigation:** Opens the corresponding application when its logo is clicked.
* 🌿 **Git Branches:** Separate development branches for the team members.
* 📁 **Application Files:** Contain the code and resources needed by the integrated applications.

The project is designed to keep the existing website theme and globe layout while providing access to the integrated applications.

## 🚀 How to Run the Project

1. 📥 Clone or download this GitHub repository.
2. 📂 Open the project folder in Visual Studio Code.
3. 🔎 Locate the main HTML file, such as `index.html`.
4. ▶️ Open it using the Live Server extension or a local web server.
5. 🌍 Explore the globe and click on the application logos.

**Note:** Some applications may open external websites or require their own internet connection. Local application pages must be available in the repository for them to run locally.

## 🌿 Branch Management

This repository uses 7 individual branches for collaborative development.

```bash
git branch
```

To switch to a team member's branch:

```bash
git switch bhargav
```

Replace `bhargav` with the relevant branch name.

To download the latest changes from GitHub:

```bash
git pull origin main
```

Before merging changes, review the code and ensure the main website continues to work correctly.
